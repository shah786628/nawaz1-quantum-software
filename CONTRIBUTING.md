# Contributing to Nawaz1

Thank you for your interest in contributing to the Nawaz1 project! This document explains how you can contribute.

## Proprietary License

The Nawaz1 project is proprietary software owned by Shahnawaz Alam. All modules are licensed under a private license (see `LICENSE` file).

## How to Contribute

Contributions to this project require a Contributor License Agreement (CLA) to be signed before your contribution can be accepted. This ensures that Shahnawaz Alam can continue to protect the intellectual property while allowing your contribution to be incorporated.

To contribute:
1. Fork the repository
2. Make your changes
3. Contact shahnawaz512001@gmail.com to request a CLA
4. Sign and return the CLA
5. Submit a pull request
6. Your contribution will be reviewed and, if accepted, merged under the proprietary license

## License Compatibility

Dependencies should be carefully chosen to maintain the integrity of the project. Acceptable licenses include:
- MIT
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- ISC
- Zlib

Do NOT add dependencies with reciprocal licenses such as:
- GPL licenses
- CDDL
- EPL

## Code Quality and Testing

All contributions should:
1. Pass all existing tests
2. Include appropriate new tests for new functionality
3. Follow the existing code style
4. Include documentation for public APIs
5. Not introduce security vulnerabilities

## Reporting Issues

If you find a bug or have a feature request:
1. Check if it's already reported in the issues
2. If not, create a new issue with a clear description
3. Include steps to reproduce for bugs
4. For feature requests, explain the use case and benefits

## Community Guidelines

1. Be respectful and professional in all interactions
2. Provide constructive feedback
3. Help others learn and grow
4. Follow the code of conduct (see CODE_OF_CONDUCT.md if available)

## Questions?

If you have any questions about contributing, licensing, or anything else:
